# clarify-first

一个面向 Agent Skill 的行为准则：**先澄清、再核实、后执行**。

它约束的不是某个具体任务，而是执行任何任务时的通用纪律——什么时候必须停下来问，什么数据可以采信，什么操作不能擅自动手。

## 解决什么问题

| 场景 | 它的要求 |
|---|---|
| 依赖缺失、权限不足、请求含糊、方案有分歧、材料不足 | 暂停，说明卡点并一次性索要所需信息，不靠猜 |
| 用户给的路径、参数、转述可能有误 | 先核实；发现矛盾就指出，不照单全收也不悄悄改 |
| 涉及删除、覆盖、范围扩张 | 决策权归用户，先列对象与影响差异再动手 |
| 结论需要数据支撑 | 须有官方背书或实机证据；无法验证就标注「未验证」 |
| 命令要穿过 PowerShell → adb → 设备 shell | 按解析链规则构造引号，禁止 `;`/`\"` 串联 |
| 任务结束 | 列出临时文件与中间状态，问用户怎么处置 |

## 目录结构

```
clarify-first/
└── SKILL.md
```

## 安装

把 `clarify-first/` 整个目录放进你所使用平台的技能目录，**目录名需与 frontmatter 里的 `name` 保持一致**。具体路径以各平台文档为准。
